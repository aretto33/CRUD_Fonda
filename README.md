# CRUD Fonda "Doña Lucha"
Aplicación web en PHP para administrar una fonda.
Incluye operaciones CRUD para clientes, productos y proveedores.

## Tecnologías
- PHP, MySQL, HTML, CSS y Nginx.

## Requisitos
- Servidor Nginx configurado.
- PHP con la extensión `mysqli`.
- Servidor MySQL.
- Base de datos llamada `Fonda`.

## Instalación
1. Clona o copia el proyecto en el directorio web de Nginx.
2. Configura Nginx para ejecutar archivos PHP.
3. Crea la base de datos `Fonda` en MySQL.
4. Revisa las credenciales en `conexion.php`.
5. Accede desde la URL configurada en Nginx.

## Módulos
- Gestión de clientes, productos y proveedores.
- Registro, actualización y eliminación de información.

Proyecto académico para practicar PHP, MySQL y operaciones CRUD.
